# OpenDrone-Scripts

This repository is retired. Reusable hardware management software belongs in
[Incutec hardware tooling](https://github.com/incutec-org/hardware-tooling),
and OpenDrone release standards and approved portfolio findings belong in the
[OpenDrone organization repository](https://github.com/OpenDrone-hw/.github).

The migration targets are:

- [hardware tooling](https://github.com/incutec-org/hardware-tooling/tree/main/hardware)
  for reusable KiCad and release-management code;
- [RELEASES.md](https://github.com/OpenDrone-hw/.github/blob/main/RELEASES.md)
  for the OpenDrone release standard;
- [engineering](https://github.com/OpenDrone-hw/.github/tree/main/engineering)
  for OpenDrone-approved findings and model data;
- each OpenDrone product repository for board-specific scripts and facts.

No new automation or configuration should be added here.
